# ServeUp — Social Development Events Platform

**Live Website:** [https://serveup-client.vercel.app/](https://serveup-client.vercel.app/)

ServeUp is a community-driven platform where people can discover, create, and participate in social development events to make a positive impact on society.

## Key Features

- **Secure Authentication:** Register and log in using email/password or Google authentication.
- **Explore Events:** Browse upcoming and past social development events.
- **Search & Filter:** Easily find events by title and category.
- **Create Events:** Authenticated users can create events with descriptions, images, dates, times, and locations.
- **Event Management:** Edit and delete events created by the logged-in user.
- **Join Events:** Participate in community events and track participant counts.
- **Personal Dashboard:** View and manage your created and joined events.
- **Theme Support:** Enjoy a responsive interface with light and dark modes.
- **Responsive Design:** Access ServeUp smoothly across desktop, tablet, and mobile devices.

## Technologies Used

- Next.js & React
- TypeScript
- Tailwind CSS
- Node.js & Express.js
- MongoDB
- Better Auth & JWT
